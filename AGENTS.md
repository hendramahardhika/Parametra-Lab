# Petunjuk proyek Parametra Lab

- Ini proyek pembelajaran CAD Autodesk Fusion untuk kelas XI Teknik Pemesinan.
- Sumber utama aplikasi ada di `app/`, `components/`, `lib/`, dan `local/`.
- `index.html` adalah hasil generate versi mandiri/offline. Jangan mengeditnya manual; setelah mengubah sumber, buat ulang dengan `npm run build:offline`.
- Gunakan `npm run dev` untuk pratinjau server lokal dengan pembaruan otomatis.
- Pertahankan pengalaman responsif untuk ponsel dan komputer, aksesibilitas dasar, serta bahasa Indonesia yang jelas untuk siswa SMK.
- Bedakan penyimpanan versi lokal browser dari penyimpanan website server/daring. Jangan menjanjikan unggahan atau sinkronisasi yang belum diimplementasikan.
- Jangan membuka, menyalin, atau membagikan `.env`, kredensial, berkas data privat, atau isi `node_modules`.
- Materi dan jobsheet adalah bahan latihan; hindari mengubah dimensi, toleransi, atau kriteria penilaian tanpa konfirmasi pemilik/guru.
