# Petunjuk proyek Parametra Lab
- Website pendamping Autodesk Fusion untuk kelas XI Teknik Pemesinan, statis dan berfungsi offline.
- Sumber aktif berada di local/. Ubah sumber lalu jalankan npm run build:offline; jangan menyunting index.html langsung. npm run dev menyajikan pratinjau lokal.
- Pertahankan empat alur belajar, akses keyboard dan seluler, bahasa Indonesia, jobsheet asli, dan penjelasan penyimpanan lokal.
- Jangan membuka, menyalin, atau membagikan .env, kredensial, berkas data privat, atau isi node_modules.
- Jangan mengubah dimensi, toleransi, atau kriteria penilaian tanpa konfirmasi guru. Distribusi siswa hanya memerlukan index.html.
